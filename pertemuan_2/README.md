# Pertemuan 2: Tipe Data dan Operator

## Topik Pembelajaran
- Tipe Data Lanjutan (List, Tuple, Set, Dictionary)
- String dan Operasi String
- Boolean Data Type
- Operator Assignment
- Operator Identity dan Membership
- Iterasi pada Struktur Data

## Daftar File

### 1. 01_data_boolean.py
Mempelajari tipe data Boolean (True/False).

### 2. 02_data_string.py
Mempelajari string sebaris dan multi-line, berbagai cara deklarasi.

### 3. 03_data_tuple.py
Mempelajari tuple sebagai struktur data immutable (tidak dapat diubah).

### 4. 04_data_set.py
Mempelajari set sebagai koleksi unik dan unordered.

### 5. 05_data_none.py
Mempelajari None sebagai nilai null dalam Python.

### 6. 06_data_dictionary.py
Mempelajari dictionary sebagai key-value pairs.

### 7. 07_data_list.py
Mempelajari list dan operasi-operasi pada list.

### 8. 08_pengenalan_list.py
Mempelajari metode-metode list (append, insert, remove, pop).

### 9. 09_fungsi_str.py
Menggunakan fungsi `str()` untuk konversi tipe data.

### 10. 10_operator_assignment.py
Mempelajari operator assignment seperti +=, -=, *=, dst.

### 11. 11_operator_identity.py
Mempelajari operator identity (is, is not).

### 12. 12_operator_membership.py
Mempelajari operator membership (in, not in).
