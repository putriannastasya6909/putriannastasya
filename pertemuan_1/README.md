# Pertemuan 1: Pengenalan Python dan Variabel

## Topik Pembelajaran
- Pengenalan Python
- Deklarasi Variabel
- Tipe Data Dasar
- Fungsi-Fungsi Dasar
- Komentar dalam Program

## Daftar File

### 1. 01_hello_python.py
Program pertama untuk mencetak "Hello Python" ke konsol.

### 2. 02_variabel_biodata.py
Mempelajari cara deklarasi variabel dan menampilkan biodata menggunakan format string.

### 3. 03_deklarasi_banyak_variabel.py
Mempelajari cara mendeklarasikan banyak variabel sekaligus dan menghitung rata-rata nilai.

### 4. 04_konstanta_python.py
Mempelajari konsep konstanta dalam Python menggunakan `typing.Final`.

### 5. 05_fungsi_type.py
Menggunakan fungsi `type()` untuk mengetahui tipe data variabel.

### 6. 06_fungsi_input.py
Menggunakan fungsi `input()` untuk menerima input dari user.

### 7. 07_fungsi_id.py
Menggunakan fungsi `id()` untuk mengetahui identitas unik objek.

### 8. 08_komentar.py
Mempelajari cara membuat komentar single-line dan multi-line.

## Konsep Kunci
- ✓ Variabel dan Deklarasi
- ✓ Tipe Data (string, int, float, bool)
- ✓ Fungsi Built-in (type, input, id)
- ✓ Komentar Program
