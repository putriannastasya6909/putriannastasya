# Pertemuan 3: Perulangan (Loop)

## Topik Pembelajaran
- Perulangan dengan For
- Perulangan dengan While
- Break dan Continue
- Nested Loop
- Iterasi pada Struktur Data
- Fungsi Range
- Perulangan dengan Kondisi

## Daftar File

### 1. 01_perulangan_for.py
Mempelajari perulangan for untuk iterasi.

### 2. 02_perulangan_while.py
Mempelajari perulangan while dengan kondisi.

### 3. 03_perulangan_while_vs_for.py
Perbandingan antara while dan for loop.

### 4. 04_keyword_break.py
Mempelajari break untuk keluar dari loop.

### 5. 05_keyword_continue.py
Mempelajari continue untuk melanjutkan iterasi berikutnya.

### 6. 06_iterasi_list.py
Iterasi pada struktur data list.

### 7. 07_iterasi_string.py
Iterasi pada setiap karakter dalam string.

### 8. 08_iterasi_tuple.py
Iterasi pada struktur data tuple.

### 9. 09_iterasi_set.py
Iterasi pada struktur data set.

### 10. 10_iterasi_dictionary.py
Iterasi pada key-value pairs dalam dictionary.

### 11. 11_fungsi_range.py
Mempelajari fungsi range() untuk membuat sequence angka.

### 12. 12_nested_loop.py
Mempelajari nested loop (loop dalam loop).

### 13. 13_perulangan_bercabang.py
Menggabungkan perulangan dengan kondisi if-else.

### 14. 14_label_perulangan.py
Teknik untuk keluar dari nested loop.

### 15. 15_fungsi_list_for.py
Menggunakan for loop dengan list.
